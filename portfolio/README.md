# Портфоліо — Владислав Лисюк

Вихідник PDF-портфоліо інженера-розробника друкованих плат.

## Файли

| Файл | Що це |
|---|---|
| `portfolio.tex` | вихідник LaTeX, закоментований українською |
| `portfolio.pdf` | зібраний документ (10 сторінок) |
| `images/` | зображення з перейменуванням під проєкти |
| `build.bat` | складання під Windows (подвійний клік) |
| `build.sh` / `Makefile` | те саме під Linux/macOS/Git Bash |

## Як зібрати

```
build.bat
```

Потрібен **XeLaTeX** (MiKTeX або TeX Live). `pdflatex` не підійде — кирилиця
підключається через `fontspec`.

## Як правити текст

Усе редагується в `portfolio.tex`; знання LaTeX не потрібне.

* Документ починається одразу з першого проєкту — без шапки з іменем і контактами
  та без вступного абзацу.
* **Кожен проєкт** позначено коментарем `% ПРОЄКТ 0X`.
* **Чипи** (теги): `\chips{\chip{Текст}\cs\chip{Текст}}` — додайте або приберіть
  `\chip{...}`, розділювач `\cs`. Зайві переносяться на новий рядок автоматично.
* **Тези** під шапкою (під які вимоги плату спроєктовано / що адаптовано):
  `\notes{ \tz Перша теза. \tz Друга теза. }` — кожна теза починається з `\tz`.
* **Моя роль**: `\role{ ... }`.
* **Зображення**:
  * на всю ширину — `\bigimg[висота]{файл.jpg}{Підпис.}`
  * парою в ряд — `\pairimg[висота]{файл1.jpg}{Підпис 1}{файл2.jpg}{Підпис 2}`

  `висота` — частка висоти сторінки (наприклад `0.40`). Це **максимум**: пропорції
  зображення зберігаються, ширина ніколи не виходить за поля. Якщо після зміни
  висоти сторінка стала напівпорожньою — зменшіть значення на `0.02–0.06`,
  щоб наступний блок піднявся вище.
* **Кольори** — блок `ПАЛІТРА` на початку файлу.
* **Шрифт** — рядок `\setmainfont{DejaVu Sans Condensed}`. Можна замінити на
  `Segoe UI`, `Calibri`, `Arial` — будь-який встановлений шрифт із кирилицею.

## Гарантія верстки

Зображення разом із підписом загорнуто в `minipage`, яку LaTeX ніколи не розриває
між сторінками. Тому зображення не може бути обрізане межею сторінки, а підпис
завжди залишається під своїм зображенням.

## Спеціальні символи

У LaTeX службові символи: `% & _ # $ { }`. Якщо потрібні в тексті — пишіть із
зворотним слешем: `\%`, `\&`, `\_`. Знак «плюс-мінус» і градус: `$\pm$`, `$^\circ$`.
