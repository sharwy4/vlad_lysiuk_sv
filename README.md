# Владислав Лисюк — CV і портфоліо плат

Сайт: **https://sharwy4.github.io/vlad_lysiuk_sv/**

Одна сторінка з резюме та сімома платами, двома мовами (укр / англ), зі світлою й темною темою.
Без фреймворків і збірки — звичайні HTML, CSS і JavaScript, GitHub Pages віддає файли як є.

## Структура

```
index.html              сторінка (розмітка порожня, вміст будує assets/app.js)
assets/
  content.js            ← ВЕСЬ ТЕКСТ САЙТУ, дві мови. Правити тільки тут
  media.js              карта «оригінал → мініатюра», створюється скриптом
  app.js                рендер, перемикання мови й теми, повноекранний перегляд
  style.css             стилі й кольори
  photo.png             фото для шапки
cv/Lysiuk_CV.pdf        резюме для завантаження
portfolio/
  portfolio.tex         вихідник PDF-портфоліо (LaTeX)
  portfolio.pdf         зібране портфоліо плат
  images/               оригінали зображень
  images/thumbs/        зменшені копії для галереї (створюються скриптом)
tools/make_thumbs.py    підготовка мініатюр
```

## Як змінити текст

Увесь текст лежить у `assets/content.js`. Кожен рядок має дві версії:

```js
{ uk: "Монтаж і паяння плат.", en: "Assembly and soldering of the boards." }
```

Змінили — зберегли — `git push`. Сайт оновиться сам за 1–2 хвилини.

## Як додати зображення

1. Покласти файл у `portfolio/images/`.
2. Виконати `python tools/make_thumbs.py` — створить зменшену копію й перепише `assets/media.js`.
3. Дописати запис у потрібний проєкт у `assets/content.js`:

```js
{ src: "portfolio/images/нове_фото.jpg", cap: { uk: "Підпис", en: "Caption" } }
```

Ключ `wide: true` розтягує зображення на всю ширину сітки.

## Як подивитись локально

```bash
python -m http.server 5173
```

Далі відкрити `http://localhost:5173`. Просто двічі клацнути `index.html` не вийде —
браузер заблокує завантаження скриптів із `file://`.

## Публікація

Гілка `main`, папка `/ (root)`, `Settings → Pages`. Кожен `git push` оновлює сайт.
Файл `.nojekyll` вимикає обробку Jekyll — без нього GitHub ігнорує деякі файли.
